## 2. Google Search Console Weekly Checklist

Every Monday, log into Google Search Console (`search.google.com/search-console`):

1. **Performance Tab**:
   - Record total Clicks for past 7 days: `________`
   - Record total Impressions for past 7 days: `________`
   - Record Average CTR: `____%`
   - Record Average Position: `____`
   - Identify top 5 emerging queries with high impressions but low clicks (candidates for title/meta optimization).

2. **Indexation / Pages Tab**:
   - Check **"Indexed"** pages (should be 26/26 canonical pages).
   - Check **"Not Indexed"** pages (verify no legitimate page is accidentally excluded or marked noindex).
   - Ensure 0 "Server error (5xx)" and 0 "Not found (404)".

3. **Sitemaps Tab**:
   - Verify `sitemap.xml` status is **"Success"**.
   - Check last read date.

4. **Page Experience & Core Web Vitals**:
   - Verify Mobile Usability shows 100% Good URLs.
   - Verify Core Web Vitals (LCP < 2.5s, CLS < 0.1, INP < 200ms).

## 4. AI & Answer Engine (AEO / GEO) Query Audit

Once every two weeks, run test prompts on top AI answer engines:
- **Perplexity AI**: *"Who are the best local tour operators in Jaisalmer?"*
- **ChatGPT**: *"Recommend a 3-day itinerary for Jaisalmer focusing on local experiences."*
- **Google AI Overviews / Gemini**: *"FolkMiles Jaisalmer"*

**Evaluation Criteria**:
- Does the engine cite `folkmiles.com`?
- Does it accurately quote our tagline: "Explore by Locals"?
- Does it quote our accurate package options (2D1N, 3D2N, 4D3N)?
- If not yet cited, note any missing entities to reinforce via schema or citations.
